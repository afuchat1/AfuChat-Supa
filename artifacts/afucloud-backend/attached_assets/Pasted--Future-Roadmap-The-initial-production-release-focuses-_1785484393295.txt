# Future Roadmap

The initial production release focuses on the Images platform. However, the architecture must be modular and extensible so future services can be added without redesigning the platform.

The following roadmap represents planned future phases and should influence the overall architecture, database design, API versioning, permission system, and storage engine.

---

## Phase 2 — Video Platform

Provide professional video infrastructure.

Planned capabilities:

* Video uploads
* Video streaming
* Adaptive bitrate streaming
* Automatic transcoding
* Thumbnail generation
* Preview clips
* Video compression
* Video analytics
* Video metadata
* Subtitle support
* Multiple resolutions
* Private and public video sharing
* Signed video URLs
* Video API
* Video processing pipeline

---

## Long-Term Vision

AfuCloud should evolve into a complete cloud platform for managing, processing, securing, and delivering digital assets through professional APIs and developer tools.

Every future service should integrate seamlessly with the existing authentication system, permission model, storage abstraction layer, API gateway, analytics engine, and developer experience without requiring fundamental architectural changes.
