---
name: Wallet receipt notifications
description: Product policy for push alerts when an account receives wallet value
---

Notify users when they receive a completed transaction, using concise, professional wording and avoiding duplicate or unrelated push alerts.

**Why:** The user asked that recipients be told what happened without spam or wasted notifications.

**How to apply:** Trigger alerts from trusted completed transaction records, deduplicate by transaction, respect payment notification preferences, and exclude self top-ups, conversions, and rewards unless the user asks otherwise.
