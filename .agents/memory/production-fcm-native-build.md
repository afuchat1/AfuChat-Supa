---
name: Production FCM requires a new native build
description: Why direct-FCM production fixes do not affect already-installed Play builds
---

A direct Firebase sender change or Edge Function redeploy cannot repair an FCM token generated by an older native binary that contains different Firebase configuration. The old token must be disabled, and the user must install a completed native build containing the corrected google-services configuration. A source upload or failed EAS job does not change the installed Play artifact.

**Why:** FCM validates the token's sender/project identity before accepting the message; the server cannot transform a token into one from another Firebase project.

**How to apply:** When preview works but Play production still reports `SENDER_ID_MISMATCH`, verify the installed Play version/build artifact and token registry before changing delivery logic. Do not claim recovery until a new AAB is built, published, installed, and a new enabled token is registered.
