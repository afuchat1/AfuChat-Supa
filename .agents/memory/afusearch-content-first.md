---
name: AfuSearch content-first discovery
description: Product rule for AfuSearch's pre-search discovery and spelling suggestions.
---

AfuSearch should expose real AfuChat content before the user starts searching. While typing, show content-backed suggestions as a ranked vertical list of tap-to-search rows, not horizontal chips. When a query has no results, only show corrected results when a close keyword match is found in existing public content or visible profiles; preserve the original query and let the user choose it instead. If no trustworthy match exists, do not guess an unrelated term.

**Why:** the user wants content discovery before search, a professional vertical suggestion list like Google or TikTok, and "Did you mean?" suggestions grounded in what exists in AfuChat.

**How to apply:** keep trending content visible on the idle screen, derive suggestions and corrections from AfuChat data rather than external or generated vocabularies, and keep an explicit route back to the exact original search.
