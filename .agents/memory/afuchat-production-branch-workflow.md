---
name: AfuChat production-branch workflow
description: The user's branch preference for urgent AfuChat fixes.
---

For urgent AfuChat fixes, work directly on the production branch instead of creating a feature branch.

**Why:** the user asked to work directly on the production level and avoid wasting time.

**How to apply:** When the user asks for urgent production-level work in AfuChat, stay on the production branch and do not create a feature branch.
